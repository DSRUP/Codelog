My First HTML Page May 2025

lesson note

73

code · html
<!DOCTYPE html>
<html>
  <head>
    <title>Hello World</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>My first webpage.</p>
  </body>
</html>
description

This is the basic skeleton of any HTML page. The <head> contains metadata, the <body> is what you see in the browser. I need to remember to always close my tags!

CSS Basics May 2025

lesson note

CSS (Cascading Style Sheets) controls how HTML looks — colours, fonts, spacing. You link a CSS file to HTML using a <link> tag in the head.

code · css
body {
  background: #f5f5f0;
  font-family: Georgia, serif;
  max-width: 700px;
  margin: 0 auto;
}

h1 {
  color: #2c2c2a;
  font-size: 2rem;
}
description

The selector (e.g. h1) targets an element, then the curly braces hold the rules. margin: 0 auto is a common trick to centre a block element.
